# Neon-Odyssey

**A neon-soaked arcade survival game where every sector is a new challenge.**

##  About the Game

Neon Odyssey is a colorful, futuristic arcade game built with HTML, CSS, and JavaScript. Enter a glowing arena, collect energy crystals, fight dangerous drones, dodge enemy projectiles, and survive increasingly difficult sectors.

Every sector brings new enemies, tougher challenges, and opportunities to upgrade your abilities. How far can you travel before the void catches up with you?

##  Features

- **Dynamic Combat:** Shoot enemies and dodge incoming projectiles in real time.
- **Crystal Collection:** Collect glowing energy crystals to earn points.
- **Progressive Difficulty:** Survive increasingly challenging sectors.
- **Boss Battles:** Face powerful bosses every third sector.
- **Upgrade System:** Improve movement speed, restore hull integrity, or increase weapon damage.
- **Particle Effects:** Experience glowing projectiles, explosions, floating score indicators, and animated effects.
- **Live HUD:** Track your score, health, crystals, sector, and mission progress.
- **Radar System:** Monitor nearby enemies and crystal locations.
- **Dash Ability:** Quickly dash through dangerous situations.
- **Sound Effects:** Enjoy synthesized arcade sounds with a sound toggle.
- **Personal Best:** Your highest score is saved locally in your browser.
- **Responsive Interface:** A neon-inspired interface designed to adapt to different screen sizes.

##  Getting Started

### Option 1: Run Locally

1. Download or clone this repository.
2. Keep all three game files in the same directory.
3. Open `index.html` in a modern web browser.
4. Click **ENTER THE GRID** to start playing.

No installation, server, or API key is required.

### Option 2: Run with VS Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if desired.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

##  Technologies Used

- **HTML5** for the game's structure.
- **CSS3** for the interface, responsive styling, and neon effects.
- **JavaScript** for gameplay logic, enemy behavior, collision detection, upgrades, and progression.
- **HTML Canvas API** for rendering the arena, projectiles, particles, and game objects.
- **Web Audio API** for synthesized sound effects.
- **Local Storage** for saving the personal-best score.

##  Objective

Collect the required crystals and eliminate every enemy to clear each sector. Choose upgrades strategically, conserve your hull integrity, and prepare for boss encounters.

Your mission is simple: survive the grid and push beyond your limits.
